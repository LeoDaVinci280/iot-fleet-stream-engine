# IoT Fleet Stream Engine

Real-time IoT fleet monitoring platform built with:

- Redpanda
- TimescaleDB
- FastAPI
- WebSockets
- Streamlit
- Docker

## Features

- Real-time telemetry ingestion
- Event-driven architecture
- Fleet monitoring dashboard
- Anomaly detection
- Time-series persistence
- Live alerts

## Architecture

Producer → Redpanda → Consumer → TimescaleDB → FastAPI → Streamlit
